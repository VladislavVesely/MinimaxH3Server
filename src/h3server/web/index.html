Authenticate securely

Host identity is trusted. Your password is sent only to this local controller for SSH authentication, never saved to disk or browser storage, and cleared from this form on submission.

With consent, this running controller reconnects for up to 120 seconds after an approved reboot or lost setup connection and replays the same saved setup. No sudo password is retained and no installation or reboot is repeated. Disconnect, session expiry, opt-out or controller shutdown clears retained credentials. A restarted controller requires authentication again. Uncheck to reconnect manually.
